# 动手构建

课程前面的级别讲解了 iMBrace 是什么，并展示了一个用例从头到尾的运行过程。这一级由你亲自动手构建一个。

## 这一级能让你收获什么

学完之后，你就能用自己已经在用的任意 AI 编程工具，在一个测试组织上构建出一个可运行的小型退货台，并让它等待人的决定。要做到这一点，不需要任何人把源代码交给你——你只需要一个测试组织、一个密钥，以及通过 MCP 连接好的编程工具。

- [设置你的编程工具](/zh-cn/learn/build-it/set-up-your-coding-tool.md)——测试组织与密钥，以及把你的编程工具连接到该组织。先做这一步。
- [在 iMBrace 上进行 Vibe Coding——动手构建](/zh-cn/learn/build-it/vibe-coding-tutorial.md)——文字教程。请按顺序跟做；它的设计就是让你在一个真实的测试组织上从头到尾走一遍。
- [让它等待人的决定](/zh-cn/learn/build-it/make-it-wait-for-a-person.md)——第二次动手：从已经完成的退货台开始，让它通过邮件询问一个人并等待答复，在此之前不向客户承诺任何事。
- [与 AI 编程工具协作](/zh-cn/learn/build-it/working-with-ai.md)——让你的工具构建出的成果保持可信的立场与护栏。

## 开始之前

- 一个测试组织和一个 API 密钥。绝不能使用生产密钥。
- 任意能够保持 MCP 连接、并能读取文本文件的 AI 编程工具。本教程刻意不指定具体工具——你现在用的是哪一个，它就能配合哪一个。
- 教程大约一小时。“让它等待人的决定”是第二次动手，需要两个你能读取的邮箱地址。

## 完成这一级之后

第 3 级“构建得好”，是这一页所教的这些习惯背后的方法：为什么每一条都重要、缺了它会是什么样子，以及如何在客户发现之前先一步看出差别。第 2 级让你构建出一个能运行的智能体，第 3 级则决定它是否值得交付。
