# About the course

This course teaches you iMBrace: understand it, see it work, build on it and build it well,
in English, Traditional Chinese and Simplified Chinese. It sits beside the SDK documentation:
the docs are the reference, and the course is a guided route through them, with screenshots.
Choose the path that fits you below.

## Downloads

- [Build guide for AI coding tools (.zip)](https://engineer.imbrace.co/learn/imbrace-build-guide-community.zip)
- [The whole course for AI tools (llms-full.txt)](https://engineer.imbrace.co/learn/llms-full.txt)

The partner kit (demo scripts, delivery and deployment guides, a practice organisation) is
not a download: ask your iMBrace contact for it.

## Choose your path

- [Explain iMBrace to a customer](/learn/understand/overview.md) - What it is, what it does today, and a tour of it working.
- [Build on iMBrace](/learn/build-it/set-up-your-coding-tool.md) - Set up your coding tool, then build a small working return desk and make it wait for a person.
- [Build with an AI coding tool](/learn/build-guide.md) - Give your tool the build guide, or the whole course as one file.
- **Work with iMBrace as a partner** - Demo scripts, delivery and deployment guides and a practice organisation, in the partner kit.

### Every page on each path, in order

**Explain iMBrace to a customer.**
[What iMBrace is](/learn/understand/overview.md), then
[What iMBrace does today](/learn/understand/capability-truth-table.md), then
[A tour of the platform](/learn/see-it-work/platform-tour.md), then
[CV screening, end to end](/learn/see-it-work/cv-screening.md) or
[Sales quoting](/learn/see-it-work/sales-quoting.md).

**Build on iMBrace.**
[Set up your coding tool](/learn/build-it/set-up-your-coding-tool.md), then
[The building blocks](/learn/build-it/building-blocks.md), then
[the tutorial](/learn/build-it/vibe-coding-tutorial.md), then
[Make it wait for a person](/learn/build-it/make-it-wait-for-a-person.md), then
[Working with an AI coding tool](/learn/build-it/working-with-ai.md), then
[Build it well](/learn/build-it-well/index.md). The hands-on tutorial takes about an hour;
Make it wait for a person is a second sitting.

**Build with an AI coding tool.**
Start with the [Build guide for AI tools](/learn/build-guide.md). Your tool can also read
[the whole course as one file](https://engineer.imbrace.co/learn/llms-full.txt).

**Work with iMBrace as a partner.**
The partner kit adds demo scripts, delivery and deployment guides and a practice
organisation. Ask your iMBrace contact for it.
