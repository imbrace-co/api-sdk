# Changelog

## 1.0.3 - 30 September 2026

- **Human approval:** a person now decides from where they already work - an email with
  Approve and Reject buttons, each opening a confirm page, where only the page's Confirm
  decides. The run waits, then the same run finishes the job and tells the requester. Deciding
  by editing a cell in a board is now named as an anti-pattern, and the review checklist asks
  where the reviewer already works.
- **The eight principles, Use-case shapes, Review checklist, Anti-patterns:** updated to match.

## 1.0.2 - 30 September 2026

- **Build it:** the Getting started page is now Set up your coding tool (`build-it/set-up-your-coding-tool.md`). It keeps the test organisation and key, the MCP connection, the SDK's map and the check that it works, and sends the SDK install and credentials to the docs' own Setup Guide instead of repeating them.

## 1.0.1 - 29 September 2026

- Chinese wording made consistent across every page - one name for each building block,
  principle and anti-pattern, the product's own on-screen labels where you click, and local
  usage throughout. No change to the guidance.

## 1.0.0 - 28 September 2026

- **Traditional and Simplified Chinese**, page for page alongside English. Every page in this
  guide - AGENTS.md, README.md, CHANGELOG.md and every lesson - now also ships as a full
  translation under zh-tw/ and zh-cn/, kept in step with the English original. AGENTS.md tells
  your coding tool to read the copy that matches the language the person writes in, and to
  treat the English page as the reference if the two ever differ.
- **Understand: two new pages**, the first from Level 0. What iMBrace is sets out the platform
  in one pass - enough to explain to a customer who might fit. What iMBrace does today lists
  what works right now, capability by capability, each one checked against a real page or the
  product itself, not a plan or a roadmap.
- **Build it: one new page**, The building blocks - the five things every iMBrace build is made
  from, plus the three ways to extend and deliver them, by name and by where each one lives on
  screen. Build it well carries over unchanged from edition 0.9.1.

## 0.9.1 - 26 September 2026

- **Human approval:** recording a decision is not the last step - the process picks back up
  on its own once the decision lands, finishing the job or telling the person who asked.
- **Anti-patterns:** four new entries - the ask that hangs up, memory as the data source, the
  pivot photograph, and the whole tab in the turn.
- **The eight principles:** human governance gains the pause-and-resume point, the matching
  way it goes wrong, and question 7; the review checklist gains the same question.

## 0.9.0 - 23 September 2026

First edition.

- **Build it:** getting started (a test organisation, the SDK, credentials, the MCP connection
  and what it covers, where iMBrace runs), the tutorial, and working with an AI coding tool.
- **Build it well:** the eight principles, use-case shapes, human approval (including a proven
  board-column pattern and four details that make a gate hold), native-first, document models,
  anti-patterns, and the review checklist.
