課程前面幾個級別說明了 iMBrace 是什麼，並展示一個使用案例從頭到尾的運作方式。這個級別則換你親自建置一個。

## 這個級別能讓你做到什麼

完成後，你就能用自己既有的任何 AI 程式碼工具，在測試組織上建置一個能運作的小型退貨櫃台，並讓它等一個人做決定。不需要任何人交給你原始碼——你只需要一個測試組織、一把金鑰，以及透過 MCP 連接好的程式碼工具。

- [設定你的程式碼工具](/learn/build-it/set-up-your-coding-tool/)——測試組織與金鑰，以及將你的程式碼工具連接到該組織。請先完成這一步。
- [Vibe coding on iMBrace：動手建置](/learn/build-it/vibe-coding-tutorial/)——書面教學。請依順序操作；它的設計是在真實的測試組織上，從頭到尾完整走過一遍。
- [讓它等一個人做決定](/learn/build-it/make-it-wait-for-a-person/)——第二次實作，從已經完成的櫃台開始，讓它以電子郵件詢問一個人，並在向顧客承諾任何事之前等候答覆。
- [與 AI 程式碼工具協作](/learn/build-it/working-with-ai/)——確保你的工具所建置的成果值得信賴的原則與防護措施。

## 開始之前

- 一個測試組織與一把 API 金鑰。絕不要使用正式環境的金鑰。
- 任何能維持 MCP 連線並讀取文字檔的 AI 程式碼工具。這份教學刻意不指名特定工具——你目前使用的任何一種都適用。
- 教學課程大約一小時。讓它等一個人做決定是第二次實作，需要兩個你能讀取的電子郵件地址。

## 完成這個級別之後

第 3 級「建置得好」，是這個頁面所教的習慣背後的方法：為什麼每一項都重要、少了它會是什麼樣子，以及如何在客戶發現之前先看出差異。第 2 級讓你建置出一個能運作的代理人；第 3 級則決定它是否值得交付上線。
