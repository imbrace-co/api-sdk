## 資料與工作流

| 你可以做什麼 | 在哪裡查看 |
|---|---|
| 在一張共用的數據表上維護結構化紀錄，讓每個工作流、代理人與使用者都能讀取與寫入 | 產品：「知識模組」、「數據表」（DataIQ） |
| 依連接頻道收到的訊息、排程，或數據表紀錄的變更——新增、刪除，或指定欄位被更新——來啟動工作流 | 產品：工作流、「流程營運模組」（FlowOps） |
| 透過預先建置的連接器，從工作流內部連接到外部系統——iMBrace 原生整合超過 100 種服務，從 CRM、試算表到工單系統都涵蓋在內 | 產品：「應用整合」（Integrations） |
| 將連接器的憑證保存在組織自己的儲存區，與工作流本身分開存放，讓分享或匯出的工作流定義不會帶有任何金鑰 | https://engineer.imbrace.co/zh-tw/sdk/workflows |
| 在重要的決策點暫停工作流，停在原處等待特定的人做出決定，對方回覆後，同一次執行就會接著往下走，並記錄是誰做了決定、決定了什麼，以及何時做的。若一直沒有人回覆，這次執行會維持暫停、清楚可見，也不會有任何東西送出去 | 產品：「流程營運模組」（FlowOps） |
| 在對方原本工作的地方請他們決定：一封附有事實卡片與兩個按鈕（「核准」與「拒絕」）的電子郵件，每個按鈕都會開啟一個頁面，讓他們在頁面上按下「確認」。打開連結不會決定任何事，而且一旦有一個答案被確認，另一個按鈕就會失效 | 產品：「流程營運模組」（FlowOps），以及寄出的郵件卡片 |
| 在答案出來之後把事情做完：核准後，完成的 PDF 與 Excel 文件會以電子郵件寄給提出請求的人；被拒絕時，會通知那個人，也不會有任何文件送出。本來就符合規則的請求則不需要核准，文件會直接寄出 | 產品：「流程營運模組」（FlowOps），以及提出請求的人的收件匣 |
