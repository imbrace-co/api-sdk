[設定你的程式碼工具](/learn/build-it/set-up-your-coding-tool/)，接著

<strong>使用 AI 程式碼工具開發。</strong>
從 [AI 工具的建置指南](/learn/build-guide/)開始。你的工具也可以讀取
[整門課程合併成的單一檔案](https://engineer.imbrace.co/zh-tw/learn/llms-full.txt)。

<strong>成為 iMBrace 合作夥伴。</strong>
合作夥伴套件另附示範腳本、交付與部署指南，以及一個練習用組織。請向你的 iMBrace 聯絡人索取。
