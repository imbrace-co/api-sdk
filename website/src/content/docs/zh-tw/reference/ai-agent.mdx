`client.aiAgent` (TypeScript) / `client.ai_agent` (Python) 提供聊天串流、嵌入管理、parquet 生成與 AI 代理的分散式追蹤。

如需逐步指南，請參閱 [SDK 指南中的 AI Agent](/sdk/ai-agent/)。

## 結構定義

### StreamChatBody

初始化串流聊天會話的參數。

| 欄位 | 類型 | 必填 | 說明 |
|-------|------|----------|------|
| `assistant_id` | string | ✓ | 要聊天的 AI 代理 ID |
| `messages` | array | ✓ | 對話歷史記錄（role + content 成對） |
| `id` | string | | 要繼續的現有聊天會話 ID |
| `model_id` | string | | 覆寫代理的預設 LLM 模型 |
| `provider_id` | string | | 覆寫代理的預設 LLM 提供者 |
| `user_id` | string | | 外部使用者識別碼 |

:::note
回應格式取決於**代理**的 `streaming` 欄位（在建立時透過 `createAiAgent` 設定），而非此 body 中的任何內容。以 `streaming: true` 建立的代理會回傳 `Content-Type: text/event-stream`（SSE — 可由 `streamChatText` / `stream_chat_text` 解析）。`streaming: false` 的代理（新建立代理的預設值）會回傳 `Content-Type: text/plain`，完整回覆為單一字串。
:::

### StreamSubAgentChatBody

| 欄位 | 類型 | 必填 | 說明 |
|-------|------|----------|------|
| `assistant_id` | string | ✓ | AI 代理 ID |
| `session_id` | string | ✓ | 父會話 ID |
| `chat_id` | string | ✓ | 會話中的聊天 ID |
| `messages` | array | ✓ | 對話訊息 |

## streamChat / stream_chat

傳回原始 HTTP `Response`。其 body 為 `text/event-stream`（當代理設定 `streaming: true` 時）或 `text/plain`（當 `streaming: false` 時）。SSE 的情況建議改用下方的 `streamChatText` 輔助方法 — 它會替你完成解析。

<Tabs syncKey="lang">
<TabItem label="TypeScript">
```typescript
const res = await client.aiAgent.streamChat({
  assistant_id: "agent_id",
  messages: [{ role: "user", content: "Hello" }],
  user_id: "user_123",
});

if ((res.headers.get("content-type") ?? "").includes("text/event-stream")) {
  const reader = res.body!.getReader();
  const decoder = new TextDecoder();
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    console.log(decoder.decode(value));   // 原始 SSE 位元組
  }
} else {
  console.log(await res.text());          // 完整回覆，純文字
}
```
</TabItem>
<TabItem label="Python">
```python
res = client.ai_agent.stream_chat({
    "assistant_id": "agent_id",
    "messages": [{"role": "user", "content": "Hello"}],
    "user_id": "user_123",
})

if "text/event-stream" in res.headers.get("content-type", ""):
    for line in res.iter_lines():
        if line:
            print(line)
else:
    print(res.text)
```
</TabItem>
</Tabs>

## streamChatText / stream_chat_text

`streamChat` 的便利包裝。它會解析 Vercel-AI-SDK UI-Message-Stream（`data: {"type":"text-delta","delta":"..."}`），並將每個文字片段以字串形式逐一產出。需要代理以 `streaming: true` 建立 — 否則伺服器會回傳 `text/plain`（沒有 `data:` 行），此產生器將產出 **0 個片段**。

<Tabs syncKey="lang">
<TabItem label="TypeScript">
```typescript
for await (const chunk of client.aiAgent.streamChatText({
  assistant_id: "agent_id",
  messages: [{ role: "user", content: "Hello" }],
})) {
  process.stdout.write(chunk);
}
```
</TabItem>
<TabItem label="Python">
```python
for chunk in client.ai_agent.stream_chat_text({
    "assistant_id": "agent_id",
    "messages": [{"role": "user", "content": "Hello"}],
}):
    print(chunk, end="", flush=True)
```
</TabItem>
</Tabs>
