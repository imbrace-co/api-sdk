### 安裝

<Tabs>
  <TabItem label="TypeScript">

**從 npm 註冊表安裝：**

```bash
npm install @imbrace/sdk
# or
yarn add @imbrace/sdk
# or
pnpm add @imbrace/sdk
```

**單一倉儲 / 本機開發：**

```bash
# 步驟 1 — 安裝相依套件並建置
cd ts
npm install
npm run build

# 步驟 2（可選）— 全域連結以在同一台機器上的另一個專案中使用
npm link
```

然後在您的外部專案中：

```bash
npm link @imbrace/sdk
```

**驗證：**

```typescript
import { ImbraceClient } from "@imbrace/sdk";
console.log("SDK loaded:", typeof ImbraceClient); // 'function'
```

  </TabItem>
  <TabItem label="Python">

**從 PyPI 安裝：**

```bash
pip install imbrace
# or
uv add imbrace
```

**單一倉儲 / 本機開發（editable 模式）：**

```bash
cd py
pip install -e ".[dev]"
```

`[dev]` 標誌會安裝：`pytest`、`pytest-asyncio`、`pytest-httpx`、`ruff`、`mypy`。

**驗證：**

```python
from imbrace import ImbraceClient
print("SDK loaded:", ImbraceClient)
```

</Tabs>

### 環境

| 名稱 | 閘道 URL | 使用時機 |
| --------- | ---------------------------------------- | -------------------- |
| `develop` | `https://app-gateway.dev.imbrace.co`     | 內部開發 |

### 設定憑證

#### 建立 `.env` 檔案

SDK 不會自動讀取環境變數 — 您直接在建構函式中傳遞憑證。`.env` 檔案是用於儲存秘密的使用者慣例；請使用 `dotenv` 或您框架的環境變數載入器來讀取它們。

```env
# 憑證
IMBRACE_API_KEY=your_api_key_here
IMBRACE_ACCESS_TOKEN=your_jwt_token_here

# 組織 ID — 隨每個請求傳送
IMBRACE_ORGANIZATION_ID=your_org_id_here

# 可選：直接覆蓋閘道 URL
IMBRACE_GATEWAY_URL=https://app-gatewayv2.imbrace.co
```

#### 取得 API 金鑰

完整說明請參閱[取得 API 金鑰](/guides/api-key)。

### 初始化客戶端

<Tabs>
  <TabItem label="TypeScript">

```typescript
import { ImbraceClient } from "@imbrace/sdk";

// 伺服器端 — API 金鑰
const client = new ImbraceClient({
  apiKey:         process.env.IMBRACE_API_KEY,
  organizationId: process.env.IMBRACE_ORGANIZATION_ID,
  env:            "stable",
});

// 客戶端 — 存取令牌（例如來自先前的登入，或你自己儲存的 token）
const client = new ImbraceClient({
  accessToken: process.env.IMBRACE_ACCESS_TOKEN,
  env:         "stable",
});

// 密碼登入（POST /v1/login/sign_in）— 終端使用者應用最常見的方式。
// 在一次呼叫中傳回 { token: "login_acc_...", organizations: [...] }；
// 用 selectOrganization() 選擇其中一個，SDK 會自動切換為該組織的 acc_ token。
const anon = new ImbraceClient({ env: "stable" });
const { organizations } = await anon.login("user@example.com", "password");
await anon.selectOrganization(organizations[0].id);

// OTP 登入流程（替代方案 — 用 email-OTP 體驗取代密碼）
await anon.requestOtp("user@example.com");
await anon.loginWithOtp("user@example.com", "123456");
// 令牌自動儲存在客戶端上
```

  </TabItem>
  <TabItem label="Python (sync)">

```python
import os
from imbrace import ImbraceClient

# 伺服器端 — API 金鑰
client = ImbraceClient(
    api_key=os.environ["IMBRACE_API_KEY"],
    organization_id=os.environ.get("IMBRACE_ORGANIZATION_ID"),
    env="stable",
)

# 客戶端 — 存取令牌
client = ImbraceClient(
    access_token="eyJhbGci...",
    organization_id="org_xxx",
)

# 密碼登入（POST /platform/v1/login/authenticate）— 終端使用者應用最常見的方式。
# login() 回傳使用者所屬的組織；選擇其一後用 select_organization()
# 將短期 login_acc_ token 換成綁定組織的 acc_ token。
anon = ImbraceClient(env="stable")
res = anon.login("user@example.com", "password")
anon.select_organization(res["organizations"][0]["organization_id"])

# OTP 登入流程（替代方案 — 用 email-OTP 體驗取代密碼）
anon.request_otp("user@example.com")
anon.login_with_otp("user@example.com", "123456")
```

### 覆蓋服務 URL

當微服務執行在不同的位址時使用（例如本機開發、專用暫存環境）。

<Tabs>
  <TabItem label="TypeScript">

```typescript
const client = new ImbraceClient({
  env: "develop",
  services: {
    aiAgent: "http://localhost:4000/ai-agent",
    dataBoard: "http://localhost:3001/data-board",
    channelService: "http://localhost:3002/channel-service",
  },
});
```

  </TabItem>
  <TabItem label="Python">

```python
client = ImbraceClient(
    env="develop",
    services={
        "ai_agent":       "http://localhost:4000/ai-agent",
        "data_board":     "http://localhost:3001/data-board",
        "channel_service":"http://localhost:3002/channel-service",
    },
)
```

### 疑難排解

##### `Cannot find package '@imbrace/sdk'`

套件未連結。從 `ts` 重新執行：

```bash
npm link
cd /path/to/your-project && npm link @imbrace/sdk
```

##### `ERR_MODULE_NOT_FOUND` 指向 `dist/` 中的檔案

套件尚未建置：

```bash
cd ts && npm run build
```

##### `ModuleNotFoundError: No module named 'imbrace'`

```bash
cd py && pip install -e ".[dev]"
```

##### `401 Unauthorized`

API 金鑰已過期或無效。請從 [Imbrace Dashboard](https://cloud.imbrace.co) 產生新的金鑰，或參閱 [API 金鑰指南](/guides/api-key)。

##### `UserWarning: ImbraceClient: no credentials provided`

未傳遞 `api_key` 或 `access_token`。如果是有意的（例如僅登入流程），請忽略此警告。否則請檢查您的 `.env` 檔案。
