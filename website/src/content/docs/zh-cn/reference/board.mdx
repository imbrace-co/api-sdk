`client.boards` 是 CRM 管道的核心数据存储 — 潜在客户、交易、任务或任何结构化数据。每个面板都有自定义字段和条目。面板也可以链接到知识中心以进行 AI 驱动的搜索。

如需逐步指南，请参阅 [SDK 指南中的数据面板](/sdk/databoard/)。

---

## Schema

### Board

| 字段 | 类型 | 说明 |
|-------|------|------|
| `object_name` | string? | 对象类型标识符 |
| `id` | string | 唯一面板 ID |
| `organization_id` | string | 所属组织 |
| `name` | string | 面板显示名称 |
| `description` | string? | 可选描述 |
| `workflow_id` | string? | 关联的工作流 ID |
| `hidden` | boolean? | 面板是否隐藏 |
| `team_ids` | string[]? | 有访问权限的团队 |
| `created_at` | string | ISO 8601 创建时间戳 |
| `updated_at` | string | ISO 8601 更新时间戳 |

### BoardField

| 字段 | 类型 | 说明 |
|-------|------|------|
| `_id` | string | 唯一字段 ID |
| `name` | string | 字段显示名称 |
| `type` | string | 字段类型（text, number, date, select 等） |
| `options` | object[]? | 类型特定配置 |
| `required` | boolean? | 字段是否必填 |

### CreateBoardInput

| 字段 | 类型 | 必填 | 说明 |
|-------|------|----------|------|
| `name` | string | ✓ | 面板名称 |
| `description` | string | | 可选描述 |
| `type` | string | | 面板类型 |
| `fields` | object[] | | 初始字段定义 |
| `team_ids` | string[] | | 有访问权限的团队 ID |
| `show_id` | boolean | | 显示 ID 列 |

## 方法

### 面板增删改查

| 方法 | TypeScript | Python | 说明 |
|--------|-----------|--------|------|
| 列出面板 | `list` | `list` | 列出所有面板 |

| 创建面板 | `create` | `create` | 创建新面板 |
| 更新面板 | `update` | `update` | 更新面板名称/描述 |
| 删除面板 | `delete` | `delete` | 删除面板 |
| 重新排序面板 | `reorder` | `reorder` | 更改显示顺序 |

### 导入 / 导出

| 方法 | TypeScript | Python | 说明 |
|--------|-----------|--------|------|

### 字段

| 方法 | TypeScript | Python | 说明 |
|--------|-----------|--------|------|

| 重新排序字段 | `reorderFields` | `reorder_fields` | 更改列顺序 |
| 批量更新字段 | `bulkUpdateFields` | `bulk_update_fields` | 同时更新多个字段 |

### 条目

| 方法 | TypeScript | Python | 说明 |

| 列出条目 | `listItems` | `list_items` | 分页的面板条目列表 |

| 创建条目 | `createItem` | `create_item` | 向面板添加条目 |
| 更新条目 | `updateItem` | `update_item` | 更新条目字段值 |

## createItem / create_item

传递一个 `fields` 数组，每个条目包含 `board_field_id`（`BoardField` 的 `_id`）和对应的 `value`。

<Tabs syncKey="lang">
<TabItem label="TypeScript">
```typescript
const item = await client.boards.createItem("board_id", {
  fields: [
    { board_field_id: "field_id_company", value: "Acme Corp" },
    { board_field_id: "field_id_deal_size", value: 50000 },
    { board_field_id: "field_id_stage", value: "Qualified" },
  ],
});
```
</TabItem>
<TabItem label="Python">
```python
item = client.boards.create_item("board_id", {
    "fields": [
        {"board_field_id": "field_id_company", "value": "Acme Corp"},
        {"board_field_id": "field_id_deal_size", "value": 50000},
        {"board_field_id": "field_id_stage", "value": "Qualified"},
    ],
})
```
</TabItem>
</Tabs>
