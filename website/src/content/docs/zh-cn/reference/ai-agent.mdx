`client.aiAgent` (TypeScript) / `client.ai_agent` (Python) 提供聊天流式传输、嵌入管理、parquet 生成和 AI 代理的分布式追踪。

如需逐步指南，请参阅 [SDK 指南中的 AI Agent](/sdk/ai-agent/)。

---

## Schema

### StreamChatBody

初始化流式聊天会话的参数。

| 字段 | 类型 | 必填 | 说明 |
|-------|------|----------|------|
| `assistant_id` | string | ✓ | 要聊天的 AI 代理 ID |
| `messages` | array | ✓ | 对话历史记录（role + content 配对） |
| `id` | string | | 要继续的现有聊天会话 ID |
| `model_id` | string | | 覆盖代理的默认 LLM 模型 |
| `provider_id` | string | | 覆盖代理的默认 LLM 提供商 |
| `user_id` | string | | 外部用户标识符 |

:::note
响应格式取决于**代理**的 `streaming` 字段（在通过 `createAiAgent` 创建时设置），与此请求体中的任何内容无关。以 `streaming: true` 创建的代理返回 `Content-Type: text/event-stream`（SSE — 可由 `streamChatText` / `stream_chat_text` 解析）。以 `streaming: false`（新建代理的默认值）创建的代理返回 `Content-Type: text/plain`，完整回复为单个字符串。
:::

### StreamSubAgentChatBody

| 字段 | 类型 | 必填 | 说明 |
|-------|------|----------|------|
| `assistant_id` | string | ✓ | AI 代理 ID |
| `session_id` | string | ✓ | 父会话 ID |
| `chat_id` | string | ✓ | 会话中的聊天 ID |
| `messages` | array | ✓ | 对话消息 |

## streamChat / stream_chat

返回原始 HTTP `Response`。响应体要么是 `text/event-stream`（代理设置了 `streaming: true` 时），要么是 `text/plain`（`streaming: false` 时）。对于 SSE 情况，推荐使用下方的 `streamChatText` 辅助方法 — 它会替你完成解析。

<Tabs syncKey="lang">
<TabItem label="TypeScript">
```typescript
const res = await client.aiAgent.streamChat({
  assistant_id: "agent_id",
  messages: [{ role: "user", content: "Hello" }],
  user_id: "user_123",
});

if ((res.headers.get("content-type") ?? "").includes("text/event-stream")) {
  const reader = res.body!.getReader();
  const decoder = new TextDecoder();
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    console.log(decoder.decode(value));   // 原始 SSE 字节
  }
} else {
  console.log(await res.text());          // 完整回复，纯文本
}
```
</TabItem>
<TabItem label="Python">
```python
res = client.ai_agent.stream_chat({
    "assistant_id": "agent_id",
    "messages": [{"role": "user", "content": "Hello"}],
    "user_id": "user_123",
})

if "text/event-stream" in res.headers.get("content-type", ""):
    for line in res.iter_lines():
        if line:
            print(line)
else:
    print(res.text)
```
</TabItem>
</Tabs>

## streamChatText / stream_chat_text

`streamChat` 的便捷封装。它解析 Vercel-AI-SDK 的 UI-Message-Stream（`data: {"type":"text-delta","delta":"..."}`），并以字符串形式逐个产出每个文本 chunk。要求代理在创建时设置了 `streaming: true` — 否则服务器返回 `text/plain`（没有 `data:` 行），此生成器将产出 **0 个 chunk**。

<Tabs syncKey="lang">
<TabItem label="TypeScript">
```typescript
for await (const chunk of client.aiAgent.streamChatText({
  assistant_id: "agent_id",
  messages: [{ role: "user", content: "Hello" }],
})) {
  process.stdout.write(chunk);
}
```
</TabItem>
<TabItem label="Python">
```python
for chunk in client.ai_agent.stream_chat_text({
    "assistant_id": "agent_id",
    "messages": [{"role": "user", "content": "Hello"}],
}):
    print(chunk, end="", flush=True)
```
</TabItem>
</Tabs>
