`client.aiAgent` (TypeScript) / `client.ai_agent` (Python) cung cấp chat streaming, quản lý embedding, sinh parquet, và distributed tracing cho AI agents.

Để xem hướng dẫn chi tiết, tham khảo [AI Agent trong hướng dẫn SDK](/sdk/ai-agent/).

## Schema

### StreamChatBody

Tham số để khởi tạo một phiên chat streaming.

| Trường | Kiểu | Bắt buộc | Mô tả |
|-------|------|----------|-------|
| `assistant_id` | string | ✓ | ID của AI agent để chat |
| `messages` | array | ✓ | Lịch sử hội thoại (cặp role + content) |
| `id` | string | | ID phiên chat có sẵn để tiếp tục |
| `model_id` | string | | Ghi đè mô hình LLM mặc định của agent |
| `provider_id` | string | | Ghi đè nhà cung cấp LLM mặc định của agent |
| `user_id` | string | | Định danh người dùng bên ngoài |

:::note
Định dạng phản hồi phụ thuộc vào trường `streaming` của **agent** (được đặt khi tạo qua `createAiAgent`), không phụ thuộc vào bất kỳ giá trị nào trong body này. Agent được tạo với `streaming: true` trả về `Content-Type: text/event-stream` (SSE — có thể phân tích bằng `streamChatText` / `stream_chat_text`). Agent với `streaming: false` (mặc định cho agent mới tạo) trả về `Content-Type: text/plain` với toàn bộ câu trả lời trong một chuỗi duy nhất.
:::

## streamChat / stream_chat

Trả về một HTTP `Response` thô. Body có dạng `text/event-stream` (khi agent có `streaming: true`) hoặc `text/plain` (khi `streaming: false`). Với trường hợp SSE, nên dùng helper `streamChatText` bên dưới — nó sẽ phân tích giúp bạn.

<Tabs syncKey="lang">
<TabItem label="TypeScript">
```typescript
const res = await client.aiAgent.streamChat({
  assistant_id: "agent_id",
  messages: [{ role: "user", content: "Hello" }],
  user_id: "user_123",
});

if ((res.headers.get("content-type") ?? "").includes("text/event-stream")) {
  const reader = res.body!.getReader();
  const decoder = new TextDecoder();
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    console.log(decoder.decode(value));   // raw SSE bytes
  }
} else {
  console.log(await res.text());          // full reply, plain text
}
```
</TabItem>
<TabItem label="Python">
```python
res = client.ai_agent.stream_chat({
    "assistant_id": "agent_id",
    "messages": [{"role": "user", "content": "Hello"}],
    "user_id": "user_123",
})

if "text/event-stream" in res.headers.get("content-type", ""):
    for line in res.iter_lines():
        if line:
            print(line)
else:
    print(res.text)
```
</TabItem>
</Tabs>

## streamChatText / stream_chat_text

Wrapper tiện lợi bao quanh `streamChat`. Phân tích Vercel-AI-SDK UI-Message-Stream (`data: {"type":"text-delta","delta":"..."}`) và trả về từng đoạn văn bản dưới dạng chuỗi. Yêu cầu agent đã được tạo với `streaming: true` — nếu không, server trả về `text/plain` (không có dòng `data:`) và generator này trả về **0 chunk**.

<Tabs syncKey="lang">
<TabItem label="TypeScript">
```typescript
for await (const chunk of client.aiAgent.streamChatText({
  assistant_id: "agent_id",
  messages: [{ role: "user", content: "Hello" }],
})) {
  process.stdout.write(chunk);
}
```
</TabItem>
<TabItem label="Python">
```python
for chunk in client.ai_agent.stream_chat_text({
    "assistant_id": "agent_id",
    "messages": [{"role": "user", "content": "Hello"}],
}):
    print(chunk, end="", flush=True)
```
</TabItem>
</Tabs>
