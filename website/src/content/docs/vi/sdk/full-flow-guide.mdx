2. **Tạo AI agent**

   `workflow_name` phải là duy nhất trong tổ chức của bạn.

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       const agent = await client.chatAi.createAiAgent({
         name: "Support Bot",
         workflow_name: "support_bot_v1",
         description: "Handles tier-1 customer support queries",
         instructions: "You are a helpful support agent. Be concise and friendly.",
         provider_id: "system",   // sử dụng nhà cung cấp LLM mặc định của tổ chức
         model_id: "Default",     // định tuyến tới model mặc định đã cấu hình của tổ chức
         streaming: true,         // phát các sự kiện SSE text-delta (xem Aside bên dưới)
       })

       const aiAgentId = agent.id  // UUID — sử dụng cho tất cả các lời gọi tiếp theo
       console.log("AI agent created:", aiAgentId)
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       agent = client.chat_ai.create_ai_agent({
           "name": "Support Bot",
           "workflow_name": "support_bot_v1",
           "description": "Handles tier-1 customer support queries",
           "instructions": "You are a helpful support agent. Be concise and friendly.",
           "provider_id": "system",   # sử dụng nhà cung cấp LLM mặc định của tổ chức
           "model_id": "Default",     # định tuyến tới model mặc định đã cấu hình của tổ chức
           "streaming": True,         # phát các sự kiện SSE text-delta (xem Aside bên dưới)
       })

       ai_agent_id = agent["id"]
       print("AI agent created:", ai_agent_id)
       ```
     </TabItem>
   </Tabs>

   `provider_id` và `model_id` là tùy chọn — SDK tự điền `{ provider_id: "system", model_id: "Default" }` khi bỏ trống. `"Default"` gắn với bất kỳ model nào mà tổ chức cấu hình làm mặc định và là lựa chọn an toàn cho mọi tổ chức. Truyền tường minh để ghi đè: `provider_id: "<uuid>"` để gắn nhà cung cấp LLM tùy chỉnh, hoặc `model_id: "gpt-4o"` v.v. — nhưng tên model cụ thể chỉ hoạt động nếu nhà cung cấp `system` của tổ chức thực sự có model đó. Liệt kê các model của tổ chức bằng `client.ai.listModels()` (TypeScript) / `client.ai.list_models()` (Python) trước khi hardcode.

   <Aside type="caution" title="Luôn truyền streaming: true cho giao diện chat">
     Agent mới tạo mặc định là **`streaming: false`** trên server. Với mặc định đó, `streamChat` trả về toàn bộ câu trả lời trong một response `text/plain` duy nhất — không có sự kiện `text-delta` — nên helper `streamChatText` (và bất kỳ parser SSE nào khác) trả về **0 chunk** và giao diện chat không hiển thị gì. Truyền `streaming: true` khi tạo sẽ khiến server phát Vercel-AI-SDK UI-Message-Stream (`Content-Type: text/event-stream`) mà `streamChatText` được thiết kế để phân tích. Bạn cũng có thể bật sau qua `updateAiAgent(id, { streaming: true })`.
   </Aside>


3. **Stream phản hồi chat bằng AI agent**

   Dùng `streamChatText` / `stream_chat_text` — helper này bao bọc `streamChat`, phân tích luồng sự kiện SSE và trả về từng đoạn văn bản thuần. Giả định agent đã được tạo với `streaming: true` (xem Aside ở bước 2).

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       for await (const chunk of client.aiAgent.streamChatText({
         assistant_id: aiAgentId,
         messages: [{ role: "user", content: "How do I reset my password?" }],
         // id là UUID phiên — tái sử dụng để duy trì lịch sử hội thoại.
         // Nếu bỏ qua, UUID mới sẽ được tự động tạo mỗi lần gọi.
       })) {
         process.stdout.write(chunk)
       }
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       for chunk in client.ai_agent.stream_chat_text({
           "assistant_id": ai_agent_id,
           "messages": [{"role": "user", "content": "How do I reset my password?"}],
           # id là UUID phiên — tái sử dụng để duy trì lịch sử hội thoại.
           # Nếu bỏ qua, UUID mới sẽ được tự động tạo mỗi lần gọi.
       }):
           print(chunk, end="", flush=True)
       ```
     </TabItem>
   </Tabs>

   <Aside type="tip" title="Đang dùng agent non-streaming?">
     Nếu agent có `streaming: false`, server trả về toàn bộ câu trả lời trong một response `text/plain` — không có sự kiện `text-delta` nào để `streamChatText` phân tích, nên nó không trả về gì. Mẫu bên dưới xử lý cả hai định dạng bằng cách rẽ nhánh theo `Content-Type`:

     <Tabs syncKey="lang">
       <TabItem label="TypeScript">
         ```typescript
         const res = await client.aiAgent.streamChat({
           assistant_id: aiAgentId,
           messages: [{ role: "user", content: "How do I reset my password?" }],
         })
         if (!res.ok) throw new Error(`HTTP ${res.status}: ${await res.text()}`)

         if ((res.headers.get("content-type") ?? "").includes("text/event-stream")) {
           // agent streaming — phân tích lại qua helper của SDK
           for await (const chunk of client.aiAgent.streamChatText({ /* same body */ })) {
             process.stdout.write(chunk)
           }
         } else {
           process.stdout.write(await res.text())   // agent non-streaming
         }
         ```
       </TabItem>
       <TabItem label="Python">
         ```python
         res = client.ai_agent.stream_chat({
             "assistant_id": ai_agent_id,
             "messages": [{"role": "user", "content": "How do I reset my password?"}],
         })
         res.raise_for_status()

         if "text/event-stream" in res.headers.get("content-type", ""):
             for chunk in client.ai_agent.stream_chat_text({ "assistant_id": ai_agent_id, "messages": [...] }):
                 print(chunk, end="", flush=True)
         else:
             print(res.text)
         ```
       </TabItem>
     </Tabs>
   </Aside>

4. **Duy trì lịch sử hội thoại (session ID)**

   Truyền cùng `id` (phải là UUID) qua các lời gọi để giữ ngữ cảnh:

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       import { randomUUID } from "crypto"

       const sessionId = randomUUID()

       // Tin nhắn đầu tiên
       await client.aiAgent.streamChat({
         assistant_id: aiAgentId,
         id: sessionId,
         messages: [{ role: "user", content: "What's your refund policy?" }],
       })

       // Tin nhắn tiếp theo — cùng phiên, AI agent nhớ ngữ cảnh
       await client.aiAgent.streamChat({
         assistant_id: aiAgentId,
         id: sessionId,
         messages: [{ role: "user", content: "How long does it take?" }],
       })
        ```
      </TabItem>
      <TabItem label="Python">
        ```python
        import uuid

        session_id = str(uuid.uuid4())

        # Tin nhắn đầu tiên
        client.ai_agent.stream_chat({
            "assistant_id": ai_agent_id,
            "id": session_id,
            "messages": [{"role": "user", "content": "What's your refund policy?"}],
        })

        # Tin nhắn tiếp theo — cùng phiên, AI agent nhớ ngữ cảnh
        client.ai_agent.stream_chat({
            "assistant_id": ai_agent_id,
            "id": session_id,
            "messages": [{"role": "user", "content": "How long does it take?"}],
        })
       ```
     </TabItem>
   </Tabs>

</Steps>

## 2. Tạo Workflow và Gắn nó vào AI Agent

<Steps>

1. **Lấy project ID của bạn**

   Sao chép Project ID từ Imbrace Dashboard → Workflows, hoặc lấy bằng code nếu tổ chức của bạn đã có flow:

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       // Cách A — hardcode từ Dashboard (khuyến nghị cho tổ chức mới)
       const projectId = "your_project_id"

       // Cách B — lấy từ một flow có sẵn (báo lỗi nếu tổ chức chưa có flow nào)
       const projectId = await client.workflows.resolveProjectId()
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       # Cách A — hardcode từ Dashboard (khuyến nghị cho tổ chức mới)
       project_id = "your_project_id"

       # Cách B — lấy từ một flow có sẵn (báo lỗi nếu tổ chức chưa có flow nào)
       project_id = client.workflows.resolve_project_id()
       ```
     </TabItem>
   </Tabs>

2. **Tạo một flow mới**

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       const flow = await client.workflows.createFlow({
         displayName: "CRM Update on New Lead",
         projectId,
       })
       console.log("Flow created:", flow.id)
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       flow = client.workflows.create_flow(
           display_name="CRM Update on New Lead",
           project_id=project_id,
       )
       print("Flow created:", flow["id"])
       ```
     </TabItem>
   </Tabs>

3. **Thêm trigger Webhook và xuất bản flow**

   Một flow mới tạo ở trạng thái **DRAFT** không có trigger — URL webhook chưa tồn tại, vì vậy `triggerFlow` sẽ trả về 404. Thêm piece Webhook làm trigger, sau đó xuất bản:

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       // Đặt piece Webhook làm trigger của flow
       await client.workflows.applyFlowOperation(flow.id, {
         type: "UPDATE_TRIGGER",
         request: {
           name: "trigger",
           type: "PIECE_TRIGGER",
           valid: true,
           displayName: "Webhook",
           settings: {
             pieceName: "@activepieces/piece-webhook",
             pieceVersion: "0.1.24",
             triggerName: "catch_webhook",
             input: { authType: "none" },
             propertySettings: {},
           },
         },
       })

       // Xuất bản — trạng thái flow chuyển từ DISABLED → ENABLED và URL webhook hoạt động
       await client.workflows.applyFlowOperation(flow.id, {
         type: "LOCK_AND_PUBLISH",
         request: {},
       })
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       # Đặt piece Webhook làm trigger của flow
       client.workflows.apply_flow_operation(flow["id"], {
           "type": "UPDATE_TRIGGER",
           "request": {
               "name": "trigger",
               "type": "PIECE_TRIGGER",
               "valid": True,
               "displayName": "Webhook",
               "settings": {
                   "pieceName": "@activepieces/piece-webhook",
                   "pieceVersion": "0.1.24",
                   "triggerName": "catch_webhook",
                   "input": {"authType": "none"},
                   "propertySettings": {},
               },
           },
       })

       # Xuất bản — DISABLED → ENABLED, URL webhook hoạt động
       client.workflows.apply_flow_operation(flow["id"], {
           "type": "LOCK_AND_PUBLISH",
           "request": {},
       })
       ```
     </TabItem>
   </Tabs>

4. **Kích hoạt flow thủ công với payload**

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       // Fire and forget (bất đồng bộ)
       await client.workflows.triggerFlow(flow.id, {
         contact_name: "Jane Smith",
         email: "jane@example.com",
       })

       // Trigger đồng bộ — để lời gọi này thực sự trả về dữ liệu thay vì hết thời gian,
       // flow cần có hành động "Return Response" được thêm qua applyFlowOperation
       // ADD_ACTION (nếu không gateway đợi 30s cho phản hồi và từ bỏ).
       const result = await client.workflows.triggerFlowSync(flow.id, {
         contact_name: "Jane Smith",
         email: "jane@example.com",
       })
       console.log("Flow result:", result)
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       # Fire and forget (bất đồng bộ)
       client.workflows.trigger_flow(flow["id"], {
           "contact_name": "Jane Smith",
           "email": "jane@example.com",
       })

       # Trigger đồng bộ — để lời gọi này thực sự trả về dữ liệu thay vì hết thời gian,
       # flow cần có hành động "Return Response" được thêm qua apply_flow_operation
       # ADD_ACTION (nếu không gateway đợi 30s và từ bỏ).
       result = client.workflows.trigger_flow_sync(flow["id"], {
           "contact_name": "Jane Smith",
           "email": "jane@example.com",
       })
       print("Flow result:", result)
       ```
     </TabItem>
   </Tabs>

5. **Gắn flow vào AI agent của bạn**

   Mở AI agent của bạn trong bảng điều khiển Imbrace, đi đến **Tools → Workflows**, và đính kèm flow. AI agent sẽ có thể kích hoạt nó trong cuộc hội thoại khi thích hợp.

   Ngoài ra, cập nhật AI agent để tham chiếu workflow theo tên:

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       await client.chatAi.updateAiAgent(aiAgentId, {
         name: "Support Bot",
         workflow_name: "support_bot_v1",
         workflow_function_call: [{ flow_id: flow.id, description: "Update CRM on new lead" }],
       })
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       client.chat_ai.update_ai_agent(ai_agent_id, {
           "name": "Support Bot",
           "workflow_name": "support_bot_v1",
           "workflow_function_call": [
               {"flow_id": flow["id"], "description": "Update CRM on new lead"}
           ],
       })
       ```
     </TabItem>
   </Tabs>

6. **Kiểm tra lịch sử chạy**

   <Tabs syncKey="lang">

     </TabItem>
   </Tabs>

</Steps>

## 3. Quản lý Knowledge Hubs và Gắn vào AI Agent

Các tệp và thư mục Knowledge Hub nằm trong dịch vụ **data-board** (`client.boards`). `_id` của thư mục là giá trị bạn truyền cho AI agent làm nguồn kiến thức.

<Steps>

1. **Tạo một thư mục**

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       const folder = await client.boards.createFolder({
         name: "Product Documentation",
         organization_id: process.env.IMBRACE_ORGANIZATION_ID,
         parent_id: "root",
       })
       console.log("Folder ID:", folder._id)
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       folder = client.boards.create_folder({
           "name": "Product Documentation",
           "organization_id": os.environ.get("IMBRACE_ORGANIZATION_ID"),
           "parent_id": "root",
       })
       print("Folder ID:", folder["_id"])
       ```
     </TabItem>
   </Tabs>

2. **Tải tệp lên thư mục**

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       import { readFileSync } from "fs"

       const fileBuffer = readFileSync("./docs/faq.pdf")
       const formData = new FormData()
       formData.append("file", new Blob([fileBuffer], { type: "application/pdf" }), "faq.pdf")
       formData.append("folder_id", folder._id)
       formData.append("organization_id", process.env.IMBRACE_ORGANIZATION_ID ?? "")

       const uploaded = await client.boards.uploadFile(formData)
       console.log("File uploaded:", uploaded.file_id)
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       from pathlib import Path

       path = Path("./docs/faq.pdf")
       files = {
           "file": (path.name, path.read_bytes(), "application/pdf"),
           "folder_id": (None, folder["_id"]),
           "organization_id": (None, os.environ.get("IMBRACE_ORGANIZATION_ID")),
       }
       uploaded = client.boards.upload_file(files)
       print("File uploaded:", uploaded.get("file_id") or uploaded.get("_id"))
       ```
     </TabItem>
   </Tabs>

3. **Gắn thư mục vào AI agent**

   Truyền `_id` của thư mục trong `folder_ids` — AI agent truy xuất từ mọi tệp trong thư mục đó. Sử dụng `board_ids` để gắn một data-board CRM (các mục của nó trở thành nguồn kiến thức — xem [Resources → Boards & items](/sdk/databoard/#items)). Trường `knowledge_hubs` cũ đã bị deprecated (không nên dùng nữa).

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       await client.chatAi.updateAiAgent(aiAgentId, {
         name: "Support Bot",
         workflow_name: "support_bot_v1",
         folder_ids: [folder._id],
         // board_ids: [boardId],  // tùy chọn: gắn thêm data-board CRM
       })
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       client.chat_ai.update_ai_agent(ai_agent_id, {
           "name": "Support Bot",
           "workflow_name": "support_bot_v1",
           "folder_ids": [folder["_id"]],
           # "board_ids": [board_id],  # tùy chọn: gắn thêm data-board CRM
       })
       ```
     </TabItem>
   </Tabs>

4. **Kiểm tra và quản lý thư mục và tệp**

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       // Tìm kiếm thư mục
       const folders = await client.boards.searchFolders({ q: "Product" })

       // Lấy thư mục với nội dung
       const contents = await client.boards.getFolderContents(folder._id)
       console.log("Files:", contents.files?.length)

       // Đổi tên thư mục
       await client.boards.updateFolder(folder._id, { name: "Product Docs v2" })

       // Tìm kiếm tệp trong thư mục
       const files = await client.boards.searchFiles({ folderId: folder._id })

       // Xóa thư mục
       await client.boards.deleteFolders({ ids: [folder._id] })
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       # Tìm kiếm thư mục
       folders = client.boards.search_folders(q="Product")

       # Lấy thư mục với nội dung
       contents = client.boards.get_folder_contents(folder["_id"])
       print("Files:", len(contents.get("files") or []))

       # Đổi tên thư mục
       client.boards.update_folder(folder["_id"], {"name": "Product Docs v2"})

       # Tìm kiếm tệp trong thư mục
       files = client.boards.search_files(folder_id=folder["_id"])

       # Xóa thư mục
       client.boards.delete_folders([folder["_id"]])
       ```
     </TabItem>
   </Tabs>

</Steps>

## 4. Quản lý Data Boards và Mục (CRM Pipelines)

<Steps>

1. **Tạo một board**

   Board là một pipeline CRM — khách hàng tiềm năng, giao dịch, nhiệm vụ, hoặc bất kỳ dữ liệu có cấu trúc nào.

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       const board = await client.boards.create({
       ```

2. **Thêm trường tùy chỉnh**

   Các loại trường là `ShortText`, `LongText`, `Number`, `Dropdown`, `Date`, `Checkbox`, v.v. `createField` trả về trường vừa được tạo. Để xem tất cả các trường trên board, hãy lấy board riêng.

   <Tabs syncKey="lang">
     <TabItem label="TypeScript">
       ```typescript
       await client.boards.createField(board._id, {
         name: "Company",
         type: "ShortText",
       })

       // Board tự động tạo một trường định danh — lấy board để xem tất cả các trường
       const boardWithFields = await client.boards.get(board._id) as any
       const identifierField = boardWithFields.fields?.find((f: any) => f.is_identifier)
       ```
     </TabItem>
     <TabItem label="Python">
       ```python
       client.boards.create_field(board["_id"], {
           "name": "Company",
           "type": "ShortText",
       })

       # Lấy board để xem tất cả các trường (bao gồm trường định danh được tạo tự động)
       board_with_fields = client.boards.get(board["_id"])
       identifier_field = next(f for f in board_with_fields.get("fields", []) if f.get("is_identifier"))
       ```
     </TabItem>
   </Tabs>
